Flag vault

Real answer checking. Flags are never stored in plain text, only salted SHA-256 hashes. Keys loaded: 0

Practice with friends: one person who knows the flags pastes them here, then clicks Download vault file. Everyone else puts flags.hash.json next to index.html (it loads by itself) or uses Load vault file. Friends can check answers but cannot read them. Challenges without a key stay format-only. Short flags can be brute-forced by a determined person, so this is for friendly practice, not strong security.

About V3

  • Loads challenges.json from the same folder. Run python3 -m http.server 8000 there, or load the file manually if prompted.
  • Submit checks the flag against the hashed key in the Vault. Challenges without a key are format-only; mark those solved yourself once the portal accepts them.
  • Notes, hints used and solve dates are stored locally. Use Export for backups.

Keyboard: press / to search, j and k to move through the list.
